# Debug Portfolio Website

## 1. Overview

This project is a four-page personal portfolio website created for the Capstone debugging task. The website presents information about my skills, projects, and contact details. The starter code was approximately 70% complete but contained intentional HTML and CSS errors that needed to be identified, fixed, and tested.

## 2. Issues Found

The starter code contained problems across the four HTML pages and CSS stylesheet. Major issues included incorrect or missing semantic HTML structure, missing metadata, incomplete navigation, missing or incorrect image alt text, an incomplete About page table, and an inaccessible contact form. The CSS also had limited selector variety, incomplete navigation and form styling, spacing and alignment problems, colour contrast issues, and insufficient responsive styling.

## 3. Fixes Implemented

I corrected the document structure and added appropriate HTML5 semantic elements including header, nav, main, section, article, and footer. I created consistent navigation across all four pages and added descriptive alt text to the website images. I added a structured skills table using thead, tbody, th, and td elements. The contact form was completed with multiple input types, labels, and HTML5 validation attributes.

I also improved the CSS by adding different selector types, box-model properties, hover and focus states, responsive styling, improved spacing, borders, table styling, and form styling. I organised the stylesheet into clear sections with meaningful comments.

## 4. HTML and CSS Structure

The website contains four HTML pages: Home, About, Projects, and Contact. Each page uses a consistent semantic structure and navigation menu. The About page contains a skills table, while the Projects page uses article elements for individual projects. The Contact page contains the completed form.

The CSS stylesheet uses element, class, ID, descendant, attribute, and pseudo-class selectors. The design uses consistent typography, spacing, borders, colours, hover effects, and responsive rules for smaller screens.

## 5. Accessibility, Testing and Reflection

Accessibility improvements include descriptive image alt text, correctly associated form labels, HTML5 validation, semantic HTML, visible focus states, and improved colour contrast.

I tested the website navigation and confirmed that all four pages can be reached through the navigation menu. I also tested the contact form validation and used the W3C HTML and CSS validators during debugging. The CSS stylesheet passed the W3C CSS validation check.

The main challenge was identifying how the different HTML and CSS issues affected the website. I solved these problems by working through the pages systematically, correcting the structure first and then improving the styling and accessibility.

## 6. How to View

To view the website locally, download or clone this repository and open `index.html` in a web browser. The other pages can be accessed through the navigation menu.
